⚡ Quickstart & Installation

astd indexes your codebase AST into a local SQLite database (WAL mode). Instead of burning millions of tokens on grep, AI coding agents get exact symbol definitions, skeletons, and call graphs in 1 turn with 95% fewer tokens.

Universal 1-Liner Installation

# macOS & Linux (curl)
curl -fsSL https://recscse.github.io/astd/install.sh | bash && astd setup

# Windows (PowerShell)
irm https://recscse.github.io/astd/install.ps1 | iex; astd setup

# Go Developer
go install github.com/recscse/astd@latest && astd setup

Editor Auto-Configuration

Running astd setup automatically wires all 14 MCP tools with autoApprove: true into:

  • Cursor IDE: ~/.cursor/mcp.json
  • Claude Desktop & Claude Code: claude_desktop_config.json
  • Google Antigravity: Registered in global agent guidelines
  • VS Code (Cline / Continue): ~/.continue/config.json
  • Windsurf: .windsurfrules

Core MCP Tools

1. pack_feature_context (95% Token Savings)

Bundles routes, models, schemas, and test suites for any feature keyword into a single 240-token payload.

2. get_file_skeleton (90% Token Savings)

Strips function bodies into /* L45-L92 */ stubs, turning 2,000-line files into concise 50-token outlines.

3. blast_radius (85% Token Savings)

Answers "If I change this symbol, what will break?" by evaluating callers and test suites across the repository.

4. find_symbol & find_callers

Instantly pinpoints exact symbol definitions and discovers all call sites across the codebase.

5. save_decision & get_decisions

Durable SQLite store for architectural invariants so future agent sessions never repeat past bugs.
