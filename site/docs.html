⚡ Quickstart & Installation

ctxd is a local-first Model Context Protocol (MCP) server that indexes AST symbols into SQLite to give AI coding agents instant repository context with 80% to 95% fewer tokens.

Universal Installation

Run the universal installer in your terminal:

# macOS & Linux (curl)
curl -fsSL https://recscse.github.io/ctxd/install.sh | bash && ctxd setup

# Windows PowerShell
irm https://recscse.github.io/ctxd/install.ps1 | iex; ctxd setup

# Go Developer
go install github.com/recscse/ctxd@latest && ctxd setup

Editor Auto-Configuration

Running ctxd setup automatically registers all 14 MCP tools with autoApprove: true into:

  • Cursor IDE: ~/.cursor/mcp.json
  • Claude Desktop & Claude Code: claude_desktop_config.json
  • Google Antigravity: Global rules and MCP registry
  • VS Code (Continue / Cline): ~/.continue/config.json
  • Windsurf: .windsurfrules

Core MCP Tools

1. pack_feature_context (95% Token Savings)

Given a feature keyword (e.g. auth, database), bundles related routes, data models, schemas, and test suites into a single 250-token context summary instead of 5 round-trips.

2. get_file_skeleton (90% Token Savings)

Strips function bodies into /* L45-L92 */ comments, compressing 2,000-line files (5,000 tokens) into 50-token skeletons.

3. blast_radius (85% Token Savings)

Evaluates caller sites and affected files across the repository to tell the AI agent what will break before refactoring.

4. find_symbol & find_callers

Instantly finds exact symbol definitions and discovers all places across the repository where a function or class is invoked.

5. save_decision & get_decisions

Allows AI agents to save and retrieve durable architectural invariants in SQLite so future sessions never repeat bugs.
