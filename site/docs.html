⚡ Quickstart & Installation

ctxd is a local-first Model Context Protocol (MCP) server that indexes AST symbols into SQLite to give AI coding agents instant repository context with 80% fewer tokens.

Universal One-Liner Install

Run the universal installer in your terminal:

# macOS & Linux
curl -fsSL https://ctxd.dev/install.sh | bash && ctxd setup

# Windows PowerShell
irm https://ctxd.dev/install.ps1 | iex; ctxd setup

Supported AI Clients

ctxd setup automatically writes the MCP configuration with autoApprove: true to:

  • Claude Desktop: claude_desktop_config.json
  • Cursor IDE: ~/.cursor/mcp.json
  • Google Antigravity: Global & workspace rules
  • VS Code (Continue / Cline): ~/.continue/config.json
  • Windsurf: .windsurfrules

Core MCP Tools

1. pack_feature_context

Given a feature keyword (e.g. auth, database), bundles related routes, data models, schemas, and test suites into a single 250-token context summary.

2. get_file_skeleton

Strips function bodies into /* L45-L92 */ comments, compressing 2,000-line files (5,000 tokens) into 50-token skeletons.

3. blast_radius

Evaluates caller sites and affected files across the repository to tell the AI agent what will break before refactoring.
