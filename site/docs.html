Documentation / Reference / Production Guide

devctx Production Documentation

devctx is a local-first code context engine and standard Model Context Protocol (MCP) server built in Go. It solves the token waste, slow grep latency, and cross-file blindness that cripple autonomous AI coding agents on large codebases.

⚡ Performance Guarantee: devctx indexes 100,000+ lines of code in ~1.5 seconds using a multi-threaded parallel goroutine pool, and executes symbol lookups, caller trees, and full-text searches in < 2 milliseconds with zero cloud dependencies.

Production Benchmarks & Token Cost Savings

Tested against standard LLM context stuffing on an enterprise monorepo (1,500 files, 100k+ lines of Java/TS/Go):

Operation Raw Agent / Grep devctx Engine Improvement
Inspecting a 1,200-line File 6,500 tokens ($0.065/turn) 120 tokens (get_file_skeleton) 98.2% Token Reduction
Cross-Repo Symbol Lookup 5–15s (unindexed grep) < 1.8 ms (find_symbol) 99.9% Faster
Refactoring Blast Radius Blind guesses & broken CI Exact callers & linked unit tests Zero Regressions
Cold Repo Indexing 30+ minutes (eager scan) 1.2 – 1.8 seconds (Parallel Pool) 1,500x Speedup

Installation & Quickstart

Install the single compiled binary and run auto-setup:

Terminal (macOS / Linux / Windows) 
# macOS & Linux (curl)
curl -fsSL https://recscse.github.io/devctx/install.sh | bash && devctx setup

# Windows (PowerShell)
irm https://recscse.github.io/devctx/install.ps1 | iex; devctx setup

# Windows (Command Prompt / CMD via curl)
curl -fsSL https://recscse.github.io/devctx/install.cmd -o install.cmd && install.cmd && del install.cmd

Then navigate to any repository root and initialize the SQLite index:

Terminal (Initialize Repository) 
cd /path/to/my-repo
devctx init

Google Antigravity & AI Agent Integration

Running devctx setup automatically registers the server into Antigravity's MCP configuration at ~/.gemini/config/mcp_config.json:

mcp_config.json 
{
  "mcpServers": {
    "devctx": {
      "command": "devctx",
      "args": ["serve"]
    }
  }
}

The 14 Production MCP Tools

When running as an MCP server (devctx serve), AI agents automatically invoke these 14 deterministic tools:

Tool Name Arguments Purpose & Impact
pack_feature_context query (string) 1-shot feature discovery: bundles models, routes, skeletons, and test suites matching a keyword.
get_file_skeleton file_path (string) Replaces function bodies with { /* L45-L92 */ } markers, cutting 95% of tokens.
blast_radius symbol (string) Traces upstream callers, impacted services, and unit test suites before modifying code.
find_symbol name (string) Returns exact file path, line number, signature, and symbol kind in <1ms.
find_callers symbol (string) Discovers all functions and line numbers where a target symbol is invoked.
find_callees symbol (string) Discovers internal dependencies and functions called inside a target implementation.
find_tests_for file_or_symbol (string) Resolves matching test suites (*_test.go, test_*.py, *.spec.ts).
get_repo_map token_budget (int) Emits an indentation-based directory hierarchy annotated with symbol signatures.
get_git_changes path (string) Summarizes uncommitted git diffs mapped to enclosing AST functions.
search_code query (string) Sub-millisecond FTS5 full-text code search across all indexed files.
read_file_context file_path, start_line, end_line Reads targeted code slices with automatic line-drift verification.
save_decision topic, decision Stores persistent architectural invariants & decisions across IDE restarts.
get_decisions topic (string) Retrieves recorded architectural memory matching a topic.
find_references name (string) Finds all usages and call sites across the entire repository.

Concurrency & Zero-Lock Architecture

Unlike naive SQLite integrations that throw database is locked (261) on agent restarts, devctx is hardened for multi-process concurrency:

  • DSN-Level Pragmas: All connections open with _pragma=busy_timeout(10000)&_pragma=journal_mode(WAL)&_pragma=synchronous(NORMAL)&_pragma=cache_size(-64000).
  • Connection Pool Governance: Max open and idle connections are strictly bounded to prevent dangling file descriptors during IDE reloads.
  • Smart Ignore Pruning: Built-in BFS directory walkers automatically prune heavy build/vendor artifacts (.gradle, .mvn, target/, node_modules/, jacoco-aggregator/).

CLI Command Reference Manual

Terminal (CLI Operations) 
# 1. Initialize repository with live progress bar
devctx init [path]

# 2. Incrementally synchronize modified files in <100ms
devctx update [path]

# 3. Clean wipe and rebuild index from scratch
devctx reindex [path]

# 4. View repository health, file count & language breakdown
devctx status [path]

# 5. Check refactoring blast radius before modifying a symbol
devctx blast <symbol-name> [path]

# 6. Instant full-text search across indexed files
devctx search "<query>" [path]

# 7. Launch interactive web architecture graph
devctx map [path] --web

# 8. Self-update devctx binary in-place to latest release
devctx upgrade
