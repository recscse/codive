Overview & Integration Guide

devctx connects directly to your local Git repository, scans the Abstract Syntax Tree (AST) across Go, TypeScript, Python, and Rust, indexes everything into an embedded SQLite database (WAL mode), and makes it searchable via Model Context Protocol (MCP), CLI, or API.

What gets indexed

  • Function & Method Declarations: Names, receiver types, argument signatures, return types, and line boundaries.
  • Structs, Classes & Interfaces: Field names, types, docstrings, and embedded interfaces.
  • Call Sites & Dependencies: Cross-file call graphs and references.
  • Test Counterparts: Automated linking between implementation files and unit tests.

1-Minute Quickstart

Run the universal installation command in your terminal:

Terminal (macOS / Linux / Windows) 
# macOS & Linux (curl)
curl -fsSL https://recscse.github.io/devctx/install.sh | bash && devctx setup

# Windows (PowerShell)
irm https://recscse.github.io/devctx/install.ps1 | iex; devctx setup

# Windows (Command Prompt / CMD via curl)
curl -fsSL https://recscse.github.io/devctx/install.cmd -o install.cmd && install.cmd && del install.cmd

Cursor IDE Configuration

Running devctx setup automatically writes your local MCP configuration into ~/.cursor/mcp.json:

~/.cursor/mcp.json 
{
  "mcpServers": {
    "devctx": {
      "command": "devctx",
      "args": ["serve"]
    }
  }
}

Claude Desktop & Claude Code Setup

Add devctx to your claude_desktop_config.json:

claude_desktop_config.json 
{

    "devctx": {
      "command": "devctx",

Core MCP Tools

1. pack_feature_context (95% Token Savings)

Given a feature keyword (e.g. auth, billing), bundles related routes, data models, schemas, skeletons, and test suites in 1 single turn (240 tokens vs 8,000 tokens).

AI Agent Tool Call 
devctx:pack_feature_context(feature="auth")

2. blast_radius (PR Regression Guard)

Evaluates all callers and affected files across the repository to tell the AI agent what will break before applying a refactor.

AI Agent Tool Call 
devctx:blast_radius(symbol="GenerateToken")

Automatic Synchronization & Updating

You never have to worry about the index going out of date. devctx maintains accurate symbol graphs through three automatic mechanisms:

  • On-The-Fly Line Drift Protection: Whenever an AI agent calls any tool (like get_file_skeleton or read_file_context), devctx checks the file's disk ModTime. If you or the AI edited the file seconds ago, it re-parses and updates SQLite in <1ms before answering.
  • Git Hooks Auto-Sync: Run devctx install-hooks once. Whenever you commit or pull code (git commit, git checkout), the repository is automatically updated in the background.
  • Live File Watcher: Run devctx watch in a background terminal to continuously index files the millisecond they are saved.

Clearing & Rebuilding the Index

To completely wipe the SQLite cache and rebuild all symbols and FTS tables from scratch:

Terminal 
# Wipe and cleanly rebuild .devctx/index.db
devctx reindex

# Or run incremental scan
devctx update
