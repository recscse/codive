Why Grep is Burning Millions of Tokens in AI Coding Agents (and How We Fixed It)

By Brijesh Yadav • August 25, 2026 • 8 min read

If you have used Claude Code, Cursor, Windsurf, or Google Antigravity on a production repository, you have likely noticed a frustrating pattern: your AI assistant takes 6 to 10 turns just searching for code, dumps thousands of irrelevant lines into the conversation history, and sometimes breaks upstream callers on refactor.

1. The Brute-Force Grep Problem

When an AI coding agent tries to discover code in your repository, its default fallback is raw grep or ripgrep. While grep is lightning-fast for humans scanning a few lines, it is disastrous for Large Language Models:

  • Noisy Results: A search for GenerateToken returns 300+ lines of mocks, tests, and comments (costing 3,800 tokens).
  • Compound Transcript Re-Sending: Because LLM APIs are stateless, that 3,800-token payload is re-sent on Turn 2, Turn 3, ... Turn 15, costing over 60,000 tokens for a simple refactor.
  • Context Degradation: Dumping entire 2,000-line files causes the model's attention to drift, leading to hallucinated method signatures.

2. Enter devctx: Local AST + SQLite WAL Mode

We designed `devctx` as an open-source, local-first context engine in Go. Instead of substring text matching, `devctx` parses Abstract Syntax Trees (AST) across Go, TypeScript, Python, and Rust, indexing symbols, signatures, and call hierarchies into a zero-lock SQLite database (WAL mode).

// 1-turn feature bundle with exact models, handlers, and skeletons (240 tokens vs 8,000) devctx:pack_feature_context(feature="auth")

3. Four Architectural Breakthroughs

1. One-Shot Feature Context Packing

Instead of 5 sequential tool turns, pack_feature_context automatically groups route entrypoints, data models, and test suites into a single 240-token summary in 1 turn.

2. The Code Skeletonizer

Rather than dumping a 2,000-line file (5,000 tokens), get_file_skeleton strips function bodies into line-annotated comments:

type PaymentProcessor struct { ... } func (p *PaymentProcessor) ProcessPayment(ctx Context, event Event) (Result, error) { /* L45-L92 */ }

3. PR Blast Radius Analyzer

Answers "If I change this symbol, what breaks?" by evaluating upstream call sites and pinpoint test suites before applying edits.

4. Persistent SQLite Agent Memory

Durable storage for architectural invariants (e.g. "PgBouncer in transaction mode; disable prepared statements") so future agent sessions never repeat past mistakes.

Conclusion

By shifting AI coding assistants from brute-force string searches to structured AST graph queries, teams cut token costs by 80% to 95% while dramatically increasing refactoring accuracy.
